# GH Brand Radar | نسخه اقتصادی (آماده استقرار، نه فعال‌شده)

## خروجی این پکیج
- `GH_Brand_Radar_Feedly.opml`: شامل **۲۴ فید** جست‌وجوی Google News؛ ۴ برند × ۶ نوع جست‌وجو.
- `config.json`: واژه‌های فارسی، انگلیسی، فاصله و نیم‌فاصله و قواعد اولویت‌بندی.
- `monitor.py`: خواندن فیدها، حذف رکورد تکراری، ثبت CSV و ارسال پیام به تلگرام (اختیاری).
- `.github/workflows/brand-radar.yml`: اجرای زمان‌بندی‌شده هر شش ساعت به‌صورت best-effort در GitHub Actions.
- `state.json`: نگهداری سابقه رکوردهای دیده‌شده.

**محدودیت مهم**: جست‌وجوهای `site:instagram.com`، `site:linkedin.com`، `site:aparat.com`، `site:bale.ai` و `site:t.me` صرفاً محتواهایی را پیدا می‌کنند که در Google News ایندکس شده باشند. این اسکریپت از خود اینستاگرام/لینکدین/آپارات/بله/تلگرام API نمی‌گیرد؛ کامنت‌ها، دایرکت‌ها و گروه‌های خصوصی را پایش نمی‌کند. نتیجه می‌تواند صفر یا بسیار کم باشد. برچسب کانال تنها نشان‌دهنده محدوده جست‌وجو است، نه راستی‌آزمایی منبع اصلی.

## مسیر A — فقط Feedly و Google Alerts (ساده‌ترین، بدون کدنویسی)
1. به Feedly بروید؛ گزینه Import OPML را پیدا کنید و `GH_Brand_Radar_Feedly.opml` را ایمپورت کنید.
2. پوشه‌های چهار برند را ببینید. فیدهای خالی یا نامعتبر را شناسایی کنید. این ۲۴ فید **تضمین دریافت نتیجه ندارند**.
3. در https://www.google.com/alerts برای هر برند، عبارت جست‌وجو از `config.json` را به‌صورت چند Alert مستقل تنظیم کنید. دریافت به ایمیل، حداقل روزی یک‌بار. Alerts به‌طور خودکار به این اسکریپت وارد نمی‌شود.
4. برای پوشش غیر ایندکس شده، اعلان‌ها و جست‌وجوی دستی حساب‌ها را طبق بخش «چک‌لیست کانال‌ها» انجام دهید.

## مسیر B — رصد دوره‌ای و هشدار تلگرام، بدون سرور اختصاصی
1. یک **مخزن خصوصی** GitHub بسازید. محتوای این پوشه را در ریشه مخزن آپلود کنید، از جمله پوشه مخفی `.github/workflows`.
2. در GitHub بخش Actions را فعال کنید و workflow به نام `GH Brand Radar` را یک بار دستی با `Run workflow` اجرا کنید.
3. اولین اجرا صرفاً سوابق را baseline می‌کند و اعلان قدیمی نمی‌فرستد. از اجرای دوم به بعد موارد جدید به `mentions.csv` اضافه می‌شوند.
4. برای هشدار تلگرام: از `@BotFather` یک Bot بسازید و **توکن را جایی عمومی قرار ندهید**. به بات در یک گروه خصوصی یا گفتگوی شخصی اجازه ارسال بدهید. Chat ID همان گفتگو را پیدا کنید (از API `getUpdates` با دسترسی خودتان یا بات مدیریتی معتبر).
5. در مخزن Settings → Secrets and variables → Actions، دو Secret بسازید: `GH_TELEGRAM_BOT_TOKEN` و `GH_TELEGRAM_CHAT_ID`. هرگز در کد، OPML یا CSV وارد نکنید.
6. برنامه هر ۶ ساعت اجرا می‌شود؛ GitHub Actions ممکن است با تأخیر یا محدودیت اجرا شود. `mentions.csv` تاریخچه قابل مشاهده در مخزن خصوصی است. خروجی صرفاً **نمایه‌ای** از اشاره‌های منتشرشده در فیدها است.
7. در صورت خطای دسترسی `git push`، در مخزن Settings → Actions → General → Workflow permissions گزینه `Read and write permissions` را تنظیم کنید، مشروط به مجوز سازمان.

اجرای محلی: `python monitor.py` (Python 3.10+؛ بدون پکیج اضافه). به اینترنت دسترسی لازم است.

## چک‌لیست تکمیلی کانال‌ها (رایگان/نیمه‌خودکار)
| کانال | کار موردنیاز | محدودیت |
|---|---|---|
| اینستاگرام | Meta Business Suite برای صندوق ورودی، کامنت‌ها و منشن‌های پیج خودتان؛ جست‌وجوی نام/هشتگ | محتوای بدون منشن، کامنت‌های دیگران و پیج‌های خصوصی کامل پوشش داده نمی‌شوند |
| لینکدین | اعلان Company Page و جست‌وجوی نام برند در Posts | API پیشرفته نیازمند مجوز و دسترسی مدیر است |
| آپارات | جست‌وجوی مستقیم نام‌های برند در ویدیوها و بررسی نظرات کانال خودتان | RSS وب فقط کشف ایندکس‌شده؛ کامنت‌ها پوشش کامل ندارند |
| بله | جست‌وجوی عمومی و بررسی کانال‌ها/گروه‌های قابل دسترسی و کانال رسمی خودتان | پایش خودکار سراسری با API عمومی در این نسخه پیاده نشده |
| تلگرام | جست‌وجو در کانال‌های عمومی / TGStat و اعلان بات برای **خروجی رادار** | بات به پیام خصوصی دیگران دسترسی ندارد؛ ارسال هشدار ≠ رصد تمام تلگرام |
| وب / خبر | Feedly + Google Alerts | محدود به منابع ایندکس‌شده و کیفیت بازیابی |
| پیام‌رسان‌های تجاری | اعلان‌ها و صندوق ورودی حساب‌های مجاز | نیازمند دسترسی ادمین و رضایت/مجوز مناسب |

## فرآیند روزانه تیم مارکتینگ
- هر روز ساعت ۹: مرور Feedly و گزارش `mentions.csv`؛ کارشناس دیجیتال مارکتینگ صاحب پایش.
- شکایت، اتهام یا ریسک: بررسی انسانی **قبل از هر اقدام**، اطلاع به روابط عمومی یا پشتیبانی، ارجاع به مالک برند. دسته‌بندی خودکار فقط بر اساس واژه کلیدی است و ممکن است خطا کند.
- سؤال اعتبار/وام: کمان‌لند؛ سؤال خرید کالا: کمان‌استور؛ سؤال قیمت/اصالت طلا: طلابرد؛ پرسش جذب پذیرنده/تسویه: ثمین‌کالا.
- برای هر مورد مهم: لینک، اسکرین‌شات مجاز، نام برند، کانال، تاریخ، مالک پاسخ، وضعیت، زمان رسیدگی ثبت شود.
- هر هفته: حجم منشن‌ها و سهم موارد حل‌شده و زمان متوسط پاسخ؛ از آمار نمایه‌ای نباید Share of Voice جامع ادعا کرد.

## امنیت و نگهداری
- مخزن را private نگه دارید؛ اطلاعات مشتری، دایرکت‌ها و PII را در CSV عمومی ثبت نکنید.
- این اسکریپت فقط عنوان و لینک‌های عمومی را ذخیره می‌کند، نه داده‌های خصوصی.
- بات تنها به گفتگوهایی که به آن مجوز داده‌اید پیام می‌فرستد.
- اگر ایمپورت OPML کار نکرد، RSS URLها را از `config.json` جداگانه اضافه کنید.
- در صورت افزایش تعداد فیدها، محدودیت و نرخ درخواست را رعایت کنید.
